Newsreader 560, optique Display : registre « atelier, papier, plume », en contrepoint d'une UI très technique. Minium #C9441F · Brou de noix #2A1A12 · Calque #FFF8F2.
Pourquoi A. C'est la seule direction où le nom, l'objet (la planche de BD) et l'UI racontent la même chose : les colonnes de l'app sont littéralement les cases de l'icône. Le vermillon de la case devient l'accent de l'interface.
Petites tailles. Sous 32 px, chaque icône passe sur un dessin simplifié (moins de cases, gouttières élargies) pour rester net sur la grille de pixels. Le glyphe de barre de menus est un template image monochrome, macOS l'inverse seul en mode sombre.
Originalité. Aucune référence à GitHub : pas d'animal, pas de forme circulaire, palette papier / encre / vermillon. À faire avant validation : recherche d'antériorité sur les marques d'apps kanban.
