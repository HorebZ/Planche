Nov 6, 2026

Alpha 8: move the window again

Drag the window from empty areas of the tab bar or sidebar, including the space above the account controls. Tabs and buttons keep their normal interactions.

Nov 6, 2026

Alpha 7: edit project drafts

Edit draft titles and Markdown descriptions with previews, offline persistence and undo. Repository boards now place blocked issues in Backlog and draft pull requests in In Progress, with matching status icons.

Nov 6, 2026

A Planche for any repository you can access

Open repository issues without a GitHub Project. The Planche view calculates five columns from issue states, blockers, assignees and linked pull requests, with label and milestone filters you can save.

Nov 3, 2026

Alpha 3: smoother board workflows

More reliable card drops and scrolling, a refined command palette with shortcut hints, and clearer move and sync notifications. A sidebar indicator now makes updates available in one click.
